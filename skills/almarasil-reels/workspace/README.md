## 3) قائمة الفحص المسبق (تقلل جولات التعديل)
> كل بند هنا كان ملاحظة من صاحب الشغل. مرّ عليها **قبل أول تسليم** لأي مشروع.

**قبل التصميم**
- [ ] الهوك: لقطة حقيقية قوية من الـRAW (لو فيه هوك مجرّب، بقّه).
- [ ] النص مصحّح بالكلمة، والغامض **مسؤول عنه** بسؤال واحد (AskUserQuestion)، مو تخمين.
- [ ] لقطة تجريبية واحدة (`v2/style.html`) للأسلوب الجديد قبل الإنتاج الكامل.
- [ ] لو فيه عنوان/مسار: لقطة خريطة + **لقطة مقرّبة للنهاية** + اتجاهات بالكلام («كمّل وخذ يمينك»).

**التصميم**
- [ ] فلات تحريري: لا زجاج، لا توهّج، لا كروت داكنة مدوّرة بظل، لا أختام دائرية.
- [ ] لا ارتداد/اهتزاز للكلمات · حركات ناعمة باتجاه واحد.
- [ ] عناصر متكاملة لما الفكرة «توافق/تكامل» (مو نسختين).
- [ ] خط التسطير بطول الجملة · لا خط تحت الشعار · نص الصندوق بالوسط بالضبط.
- [ ] لا عنصر يلمس زاوية الإطار/حافة الشاشة/عنصر ثاني (اترك ≥30px) · التسميات ما تنقص عند الحافة.
- [ ] أيقونات التواصل حقيقية (`contactRow`) بكل صفحة وبالأوترو.
- [ ] اللاتيني LTR (N70 مو 70N) · الأرقام معزولة.
- [ ] الكابشن ما يكرر نص معروض بالرسمة (NOCAP).

**الصوت**
- [ ] كل حركة/انتقال له مؤثر **مسموع** على سماعة الجوال (طرقة مع كل ساب).
- [ ] **ذروة كل whoosh على منتصف انتقاله** (الانتقال داخل الفصلة ويستقر على أول كلمة) · افحص فريمات كل قطع سكشن.
- [ ] الهوك = whoosh منظّم يتبع كيرف سرعة الكاميرا (⛔ جرس/رنّة) · جاذب انتباه + أصوات تيبوجرافي (تك فوق 4kHz) + انتقالات.
- [ ] فصل سكشنات الكلام بالتناوب: استراحة صمت تام / جسر صوتي (`SECTIONS` · 08/v2/build.py).
- [ ] الكابشن والكلمات فوق الفيديو: ظل على الكلمة، ⛔ ستروك ⛔ صندوق.
- [ ] ولا مؤثر يغطي كلمة (التقرير: 0 تحت 12 dB عدا الأجراس) · الأوترو تكة وحدة · لا شي «كأنه موسيقى».

**التسليم**
- [ ] البوابات بالأرقام (CLAUDE.md) · ورقة qc من الملف المرمّز · معاينة 720p للإرسال · اذكر اللي ما انفحص.

## 4) سير العمل
```bash
cd OPUSGRAPHIC
bash kit/tools/new_project.sh 04-<اسم> "<RAW.mp4>"          # قالب + src.mov + تفريغ medium
# ← صحّح fixes.json · عدّل KEEP/EDL/SPLITS/NOCAP بـv2/build.py · المشاهد بـv2/scenes.js (القالب = Promax كامل)
bash kit/tools/run.sh projects/04-<اسم> build
bash kit/tools/run.sh projects/04-<اسم> preview 1.0 4.5 …    # ← اقرأ v2/sheet.jpg
bash kit/tools/run.sh projects/04-<اسم> full                  # بالخلفية
bash kit/tools/run.sh projects/04-<اسم> qc t1 … t9 ; … sync
bash kit/tools/run.sh projects/04-<اسم> deliver 04-<اسم-عربي> <بادئة> v1
bash kit/tools/run.sh projects/04-<اسم> clean
```
خريطة: `python kit/tools/fetch_osm.py projects/NN "<نقطة البداية>"` ← عبّي route/iJ/company ← `node v2/map_anim.js <dir>` + ffmpeg (GUIDE §14).
