## ⛔ القواعد الحمراء (كل وحدة كلّفت صاحب الشركة جولة تعديل)
كاملة بـ`$WS/CLAUDE.md` — أهمها:
1. لا تخترع حقيقة ولا رقم ولا سعر ولا كلام. المصطلحات كما يقولها المتكلم (الكوستك، صابون صلب…).
2. لا تستبدل هوك مجرّب (فتح البرميل جاب 30 ألف مشاهدة). الهوك لقطة حقيقية قوية من الخام.
3. الموشن **فلات تحريري**: كتل صلبة، زوايا حادة، كشف بقناع. ⛔ زجاج، توهّج، ظلال مبالغة، أختام دائرية، ارتداد، «يهتز ويرجع».
4. لا شي يلمس الحافة (≥30px نفَس) · النص بالصندوق بالوسط بالضبط · خط تحت العنوان = بطول الجملة · ⛔ خط تحت الشعار.
5. الصوت: المؤثرات تنسمع وما تمس الكلام · ذروة الـwhoosh = منتصف الانتقال · الهوك whoosh على كيرف الكاميرا (⛔ جرس) · السكشنات بالتناوب استراحة/جسر · الأوترو تكة وحدة · ⛔ ملف صوتي/موسيقى تحت الكلام.
6. ⛔ لا نشر ولا رفع ولا إرسال لأي حساب — التسليم ملف فقط.

## سير العمل (كل مرحلة بأمر واحد)
```bash
cd ~/AlMarasil-Reels
bash kit/tools/new_project.sh 09-<اسم> "<الفيديو الخام>"      # قالب + تفريغ medium (دقايق — بالخلفية)
#  ← صحّح fixes.json · KEEP/EDL/SPLITS/NOCAP بـv2/build.py · المشاهد بـv2/scenes.js (القالب = Promax كامل)
bash kit/tools/run.sh projects/09-<اسم> build
bash kit/tools/run.sh projects/09-<اسم> preview 1.0 4.5 …     # ← اقرأ v2/sheet.jpg، واعرضها قبل الرسم الكامل
bash kit/tools/run.sh projects/09-<اسم> full
bash kit/tools/run.sh projects/09-<اسم> qc t1 … t9 ; bash kit/tools/run.sh projects/09-<اسم> sync
bash kit/tools/run.sh projects/09-<اسم> deliver 09-<اسم-عربي> <بادئة> v1    # ← OUT/
bash kit/tools/run.sh projects/09-<اسم> clean
```
- `new_project.sh` يكتب `fixes.json` = كلام وِسبر كما هو (جملة لكل سطر) ← صحّحه كلمة بكلمة **بنفس عدد الكلمات** لكل جملة.
- `v2/build.py` بالقالب مضبوط على فيديو التكسابون (مثال): `KEEP` (المقاطع المحفوظة) · `EDL` (الصورة) · `SPLITS` (تقسيم الكابشن) · `NOCAP` — **أعد كتابتها لكل فيديو**؛ الـassert يوقفك لو التقسيم ما يطابق الكلام، و`run.sh build` يطبع آخر الخطأ.
- مشاهد `v2/scenes.js` بالقالب كمان مثال التكسابون — بدّل نصوصها وتوقيتاتها بكلام الفيديو الجديد. مشهد الخريطة يحتاج `fetch_osm.py` أولاً وإلا يطلع فاضي.

قبل التصميم: مرّ على **قائمة الفحص المسبق** بـ`README.md` §3 كاملة. الغامض = سؤال واحد، مو تخمين.
قبل ما تكتب مشهد جديد: دوّر مشهد مشابه بـ`examples/*/v2/scenes.js` وابنِ عليه (`panelIn` · `contactRow` · `restoreBanner` بالقالب).
**أحدث أسلوب معتمد = مشروع 08** (`examples/08-personal-perfumes/v2/`): ظل الكلمة `stxt()` بـ`scenes.js` ومكتبة `kit07.js` (`K07.banner()` للفيديو بلا بانر محروق، الباكشوت، الكشيدة) — انسخ `kit07.js` لمشروعك وخذ `stxt()` منه بدل ما تكتبها من جديد.
خريطة موقع الشركة: `python kit/tools/fetch_osm.py projects/NN "<نقطة البداية>"` (GUIDE §14) + لقطة مقرّبة لنهاية المسار.

## بوابات التسليم (بالأرقام — لا تسلّم بدونها)
`audio`: −14 ±0.3 LUFS · ذروة ≤ −1.5 dBTP · 0 كلمات تحت 12 dB (عدا الأجراس المقصودة) → `sync`: وسيط ≈0، أقصى ≤0.3 ث → `qc`: ورقة 9 من **الملف المرمّز** → حجم < 30MB → `deliver` → اذكر بصراحة اللي ما انفحص.

## الجهاز
رام 8GB ← المراحل وحدة ورا الثانية (لا رندر ووِسبر سوا). الرسم الطويل بالخلفية ممكن ينقتل لما تقل الرام — شغّله أمامياً بدفعات أو سكّر البرامج الثقيلة بإذن الموظف.
